# Brainrot Simulator

A 3D Roblox-style simulator game that runs in the browser, built for Chromebooks. The whole game is one file, `index.html`, using [Three.js](https://threejs.org/) for the 3D.

## How to play

| Key | Action |
| --- | --- |
| WASD or arrow keys | Move |
| Space | Jump |
| Click | Swing your tool |
| Drag | Look around |
| Scroll | Zoom |

1. Swing at Rizz Rocks to fill your backpack with Brainrot.
2. Stand on a green **SELL** pad to turn Brainrot into Aura.
3. Spend Aura at the blue **SHOP** pad on better tools (more Brainrot per hit) and bigger backpacks.
4. Hatch pets at the purple **EGGS** pad. Your best 3 pets follow you and multiply every hit.
5. Unlock new zones at the red gates: **Ohio** (Sigma Crystals) and **Toilet Kingdom** (Golden Toilets).

Progress saves automatically in the browser.

## Run it

Open `index.html` in Chrome. To share it, turn on GitHub Pages for this repository (Settings → Pages → deploy from the branch) and open the link it gives you.
